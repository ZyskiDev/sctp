Installing the mod

Shop Logger is a client-side Fabric mod, and it only needs to be installed on your own computer, not the server.

1. Install Fabric Loader

Download and run the installer from fabricmc.net, be sure to choose the same Minecraft version you play. Pick "Client" and hit Install. This is not needed if you already have Fabric installed. The minimum version is 0.19.3!

2. Get Fabric API

Shop Logger needs Fabric API installed alongside it - it's not optional! Download the version matching your Minecraft version.

3. Download Shop Logger

Grab the jar for your Minecraft version from the Trading Post homepage ("Download mod") - there are separate versions for 1.21.11, 26.1, and 26.2, so be sure to pick the right one!

4. Drop both jars into your mods folder

Open your Minecraft folder (%appdata%\.minecraft on Windows) → mods. Put the Fabric API jar and the Shop Logger jar in there together.

5. Launch with the Fabric profile

In your launcher, select the "Fabric Loader" profile the installer created, and press Play. Shop Logger loads automatically!

Note: The above steps are for the official Minecraft launcher. If you use a third-party launcher, the steps may differ slightly, but the general idea is the same: make sure to use Fabric, then put both jars in your mods folder.

How it works

The mod reads shop signs and their chest contents, and shares that data with a website everyone can search.

1

World detection. On join, the mod figures out whether you're on Firefly or Honeybee by sending /help silently.

2

Scanning. Right-click a shop chest yourself, or let the mod scan known shops automatically if you walk within range. It will read the sign and whatever's in the chest. This causes the chest textures to look like they're opening!

3

Logging. Every scan updates a locally stored log with item, price, stock, seller, and position, and sold-out/removed shops get cleaned up as well.

4

Uploading. Your log gets uploaded to the shared Trading Post (manually with a keybind, or automatically every 15 minutes), and added to the big list!

5

Browsing. The website reads that shared data, so you can search, filter, and sort every shop on the server in one place. You can also search from in-game with /search <item>.

Main features

Manual & automatic scanning

Right-click a shop to log it, or let the mod scan nearby known shops silently as you walk past.

Shared Trading Post upload

Sends your scans to the shared website everyone can browse.

In-game /search

Look up an item straight from chat without switching to the website.

Searchable website

Filter by world, currency, price, stock, listing type, and more!

Smaller features explained
  • [DISPLAY] signs

    are supported as well!

  • Shulker / bulk detection

    A shulker box that's full of one item gets logged as bulk!

  • Enchanted book naming

    Enchanted books are logged with the actual enchantment name instead of the useless "Enchanted Book".

  • Chat scan log

    An optional toggle that tells you everything found in a scan in chat, especially for tina :D

  • Recently-scanned markers

    An optional particle over chests you've scanned recently, so you can see what's already been logged.

  • Automatic cleanup

    Sold items, emptied chests, and shops that no longer exist get removed from the website automatically

  • Keybindings

    Export, toggle auto-scan, toggle markers, toggle chat log, and manual upload are all bindable under Controls → Shop Logger (unbound by default except auto-scan).
